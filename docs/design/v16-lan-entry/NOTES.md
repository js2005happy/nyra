状态：用户 2026-11-23 选定方案 C，已在 0.5.10 落地（`mobile/www/index.src.html`）。本目录是设计稿存档：`a.png` / `b.png` / `c.png` 三稿、`compare.png` 对比图、`built-*.png` 落地后真实页面四种状态截图（412×916 @2x）。

三稿基于 v0.5.9 的 mobile/www/index.html，只替换登录区 `.sepl + #lanBtn` 那一段并追加 CSS；生成脚本未入库。

## 现状诊断
- 设置列表行的写法（32px 灰方块图标 + 两行字 + 右箭头），和上面 50px 圆角按钮不是同一套组件，像个附属项。
- #323236 实心灰方块是整个首屏唯一的实心图标底座，又重又生硬；左对齐行和居中按钮也对不上。
- 分隔线 + 贴底，读起来像「其它设置」，可它恰恰是**现在唯一能用**的入口（账号登录还是「即将推出」）。
- 回访用户每次打开都得点进去再点「连接」（地址已被记住，但首屏看不出来）。

## 配对方式（按代码核实）
- App 内：填电脑地址 + 端口 + 6 位配对码 → 跳 `http://host:port/m#pair=…`；已配对的手机可以不填码。
- 终端里的二维码里是同一个 /m 链接，用的是系统相机/浏览器，**APK 里没有扫码功能**，所以三稿都不写「扫码」。
- 上次的地址存在 localStorage `nyra-last-gateway`，C 的「直接连上次的」= goLan(last.host, last.port, '')，是现有能力。

## 方案
- A 两组同族按钮：新增「不用账号，现在就能连」组头（右侧：同一 Wi-Fi + 6 位配对码），入口是和 GitHub/邮箱同形同重的整行按钮。
- B 轻量文字链 + 小插画：去掉分隔线，灰色线稿「方块头 ┄ 电脑」+「连家里电脑 同一 Wi-Fi ›」，48px 高。
- C 可展开卡（推荐）：#161618 内嵌卡，展开时显示上次连的电脑 + 「直接连上次的 / 配对新电脑」两个 44px 按钮；第一次用没有记录时只显示「配对新电脑」。

紫色只留给品牌标志，三稿都没有新增紫色；Google 仍是唯一的白色按钮。
