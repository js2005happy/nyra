# Nyra bot 形象：紫色团子

团子是 Nyra 的 agent 形象：会话、状态行、审批卡、任务页、手机列表里代表「正在替你干活的 Nyra」的那个小角色。一个彩色实心团子，两只深色竖胶囊眼，没有嘴、没有高光、没有渐变；只靠眼睛表达状态。

Nyra 默认助手是紫色圆团子。另外 7 个是伙伴 agent 的示例形象（巡检、夜班、测试员、文档、周报、调研、翻译），名字都是示例数据；自建多个 agent 属于计划功能，界面里标「即将推出」。

应用图标用的是同一只团子变成的圆角方块，见 [`../icon/`](../icon/)。

| `screens/` | 团子在界面里的样子（2x 渲染，示例数据）：`pc-33` 会话、`pc-34` 详情页等你确认、`pc-37` 任务页、`pc-38` 新建 agent（即将推出）、`m-16` 手机对话、`m-17` 手机首页 |

文件名里的 agent：`nyra` 默认助手 · `patrol` 巡检 · `night` 夜班 · `tester` 测试员 · `docs` 文档 · `weekly` 周报 · `scout` 调研 · `lingo` 翻译。
状态：`idle` 空闲 · `think` 思考 · `work` 工作中 · `wait` 等你确认 · `done` 完成。

## 尺寸

| 尺寸 | 用在 |
| --- | --- |
| 18px | 任务页列表、状态行、行内标记 |
| 26px / 32px | 消息流里的发言人头像 |
| 46px | 桌面侧栏会话列表 |
| 54px | 手机会话列表 |
| 64px | 详情页标题 |
| 144px 预览框 | 新建 agent 预览（即将推出） |

小尺寸规则：≤ 20px 眼睛放大 18%，≤ 28px 放大 8%；问号只在 ≥ 32px 时画，更小时靠睁大的圆眼和行内的「等你确认」标记表达。

## 5 种状态（只改眼睛）

| 状态 | 眼睛 |
| --- | --- |
| 空闲 | 竖胶囊 |
| 思考 | 竖胶囊略小，看向右上 |
| 工作中 | 眯眼（两条横胶囊） |
| 等你确认 | 睁大圆眼 + 右上问号（≥ 32px） |
| 完成 | 弯眼笑 |

## 在界面里的用法

- **实时状态行**：运行中只显示一行「团子（当前状态的眼神）· Nyra · 正在做什么 · 已用时间」，团子用 18px，眼神随状态切换（思考 → 工作中 → 完成）。
- **会话列表**：每条会话前是负责它的 agent 团子，需要你处理时显示「等你确认」眼神并带警示色计数。
- **审批卡**：Nyra 需要你放行时，消息头像和详情页标题换成「等你确认」眼神（睁大圆眼 + 问号），卡片本身是一句话说明 + 「这一步能动到什么」框 + 主按钮「允许一次」。
- **消息流**：发言人名字用头像色，字重 regular。
- **任务页**：每个任务行用 18px 团子表示进度状态。
- **品牌位**：应用图标、favicon 用 `../icon/` 的定稿 C（同一只团子的方块形态），不在品牌位放伙伴 agent 的头像。
