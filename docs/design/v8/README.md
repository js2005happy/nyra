## 标了「设计提议」或「即将推出」的地方
- 设计提议：pc-39 技能确认卡和自动化确认卡（FEATURES.md 没写 agent 改自动化或技能时会不会先出确认卡）；pc-33b 会话里的记忆回执（打开、撤销）；pc-03 记忆条目的来源标注、写入回执和撤销。代码里 MEMORY.md 条目已经记了 source_session 和时间，也有按条删除，但界面上没有这些功能。
- 即将推出：pc-39「电脑关着也能跑（云电脑）」；侧栏「我的 agent」分组（沿用 v6.2）。
- 没有画：Side Chat、内置浏览器、Agent Library、Families、每个 agent 各自的 Brain、Look、Voice。这些都是 Nyra 没有的功能。

## 待定
1. 每条回复底部现在只写「用时 · token」。如果产品能按单条回复拿到花费，可以再加上花费。
2. 记忆来源暂时写成「你在「某对话」里说的」或「Nyra 在「某对话」里记下」。代码只记了来源会话，没区分是用户说的还是 Nyra 推断的，所以这个区分也属于设计提议。
3. pc-34 的会话里和抽屉里各有一组按钮，对应同一个请求。如果觉得重复，可以只保留抽屉里的那组。

## 构建
`python3 build8.py` 生成 `html/`，`python3 render8.py` 生成 `*.png`（2x），`python3 check8.py` 做检查，`python3 sheets8.py` 生成 `overview.png`。
check8 逐屏检查溢出、裁切、对比度（AA 4.5）、缺字、孤字、手机触控区（≥44）和旧名（整词）。11 屏全部通过。实时状态行的扫光字是渐变填充，脚本测不了对比度，已经用眼睛看过。
脚本只读引用工作区里的 `nyra-design/v5/icons.py`、`v5/fonts`、`v6/out-6.2`（styles62、build62、avatars）和 `v6/out-6.3`（styles63、build63）。仓库里的副本仅供查看源码。仓库内源文件在 `source/`（脚本）与 `source/html/`（各屏 HTML）。
