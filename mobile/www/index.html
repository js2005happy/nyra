用账号登录

登同一个账号，手机和电脑看到同一份状态；不用跟电脑连同一个 Wi-Fi。
旧版：连家里电脑（局域网）

连接电脑

  1. 电脑上跑 nyra ui --pair，终端里会打印二维码和 6 位配对码。
  2. 手机和电脑连同一个 Wi-Fi。
  3. 上面填电脑地址（终端里打印的那串 IP）和配对码，点连接。
  4. 配对成功后这台手机就记住了，下次直接打开就行；配对码 5 分钟有效、只能用一次。

现在 agent 在云端跑，不在你电脑上。上面登完账号就直接用云端；下面“旧版”是云端没上线前的过渡入口，等云端走通后会去掉。旧版仍是明文 HTTP，只在自己信任的家庭 Wi-Fi 里用，绝不要把端口映射到公网。手机丢了，第一时间在电脑的设置 → 手机里撤销。
