连家里电脑

云端上线前，手机通过家里的 Wi-Fi 连你的电脑。

1电脑上运行 nyra ui --pair，终端会显示二维码和 6 位配对码。
2手机和电脑连同一个 Wi-Fi，在下面填好。
配对码首次连接时填
配对码 5 分钟内有效，只能用一次，输错 5 次作废。已配对过的手机不用填。
明文连接，只在自己信任的家庭 Wi-Fi 里用，绝不要把端口映射到公网。手机丢了，在电脑的设置里撤销它。

云端地址

告诉手机连哪个云端，填一次就会记住。云端账号登录上线后，用的就是这个地址。

不知道地址？在电脑上运行 nyra cloud status 查看。

账号登录即将推出

用 Google、GitHub 或邮箱登录、手机直连云端，这一步还没上线。现在请用“连家里电脑”，在同一个 Wi-Fi 下用配对码连接。
